# EduGestão

Sistema administrativo escolar (React + Next.js), pronto para GitHub e Vercel.

## Subir no GitHub (pelo celular ou computador)

1. Crie um repositório novo em https://github.com/new (ex.: `gestao-escolar`), deixe **vazio** (sem README/gitignore).
2. Na página do repositório, clique em **"uploading an existing file"**.
3. Arraste todos os arquivos e pastas deste zip (mantendo a estrutura de pastas `app/`, `public/`, etc.).
4. Confirme o commit ("Commit changes").

## Conectar ao Vercel (deploy automático a cada push)

1. Acesse https://vercel.com/new
2. Selecione o time **EVORA**.
3. Importe o repositório que você acabou de criar no GitHub.
4. O Vercel detecta Next.js automaticamente — não precisa mudar nada. Clique em **Deploy**.

Depois disso, qualquer alteração enviada ao GitHub gera um novo deploy automático, do mesmo jeito que seus outros projetos.
